#  Academic Portfolio

Responsive academic portfolio website built from the CV.

## Files
- `index.html` - website content
- `style.css` - responsive styling
- `script.js` - navigation, tabs, and back-to-top behavior
- `assets/Janith_Dassanayake_CV.pdf` - downloadable CV

## How to use with GitHub Pages
1. Create a GitHub repository.
2. Upload all files and the `assets` folder.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/root` folder.
6. Save and wait for GitHub Pages to publish.

## Optional edits
- Replace the placeholder `#` links for Google Scholar, GitHub, and LinkedIn in `index.html`.
- To add a real photo, put `profile.jpg` inside the `assets` folder and replace the avatar block using the comment in `index.html`.
